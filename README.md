**🔗 الموقع الرسمي: https://codeex.dev**

### ✨ علاش Codeex ؟
النقاشات البرمجية العربية مشتتة في فايسبوك ومواقع أجنبية كتخربق الكود والعربية.
Codeex جمع كلشي في بلاصة وحدة باش تشارك مشاريعك، تطرح أسئلتك، وتكتب مقالاتك بكود منسق 100%.

### 🚀 شنو تقدر تدير؟
- 📝 نشر مقالات تعليمية (حتى 1000 كلمة)
- 💬 طرح نقاشات وأسئلة برمجية
- 🚀 مشاركة مشاريعك مع رفع ملفات حتى 3MB
- 🔗 نشر موارد ومقتطفات مفيدة
- 👥 الانضمام لمجتمعات Python, JavaScript, AI أو إنشاء مجموعتك

### 🔥 المميزات
- محرر كود يشبه VS Code (ترقيم، تلوين، زر نسخ)
- واجهة 100% عربية RTL + وضع ليلي ونهاري
- رسائل خاصة، إشعارات، وحفظ المنشورات
- ملف شخصي مع @username وإحصائيات المشاريع
- حماية من السبام (10 دقائق بين المنشورات)

### 🛠️ مبني بـ
- Frontend: HTML5, CSS3, Vanilla JS (SPA)
- Backend: Firebase Auth & Firestore
- Security: App Check + reCAPTCHA Enterprise
- Hosting: GitHub Pages
