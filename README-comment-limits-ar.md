# نشر حدود التعليقات والاحتفاظ بالإشعارات في Codeex

تحتاج الحدود الصارمة إلى Callable Cloud Function باسم `addComment`. تستخدم الوظيفة معاملة واحدة على تعليقات المنشور، وتحتسب التعليقات القديمة، بما فيها ما حذفه المشرف لاحقاً. لا تفعّل منع الكتابة المباشرة قبل توفر الوظيفة والواجهة الجديدة.

## الترتيب الآمن للنشر

1. من نسخة هذا الفرع في المشروع، انشر الوظيفة أولاً:

   ```bash
   npm --prefix functions install
   npx firebase-tools login
   npx firebase-tools deploy --only functions:addComment --project codna-f8612
   ```

2. اختبر أن `addComment` تعمل في `europe-west1`.
3. انشر/ادمج ملفات الموقع من هذا الفرع إلى فرع النشر؛ الواجهة الجديدة سترسل التعليقات إلى الوظيفة.
4. بعد ظهور نسخة الموقع الجديدة مباشرة، انسخ `firebase.database.rules.json` إلى Firebase Console → Realtime Database → Rules ثم انشر القواعد. لا تنشر هذا الملف إلى GitHub. بعد القواعد، قد تحتاج الصفحات القديمة المفتوحة إلى إعادة تحميل حتى تستخدم الواجهة الجديدة.

لا تنشر القواعد قبل الخطوة 3؛ النسخة القديمة من الموقع تكتب التعليقات مباشرة وقد ترفضها القواعد الجديدة. أثناء الفترة القصيرة بين الخطوتين 3 و4 قد تستطيع جلسة قديمة الكتابة مباشرة، لذا أتمم الخطوتين متتاليتين.

## ما تفرضه الوظيفة والقواعد

- 40 تعليقاً كحد أقصى لكل منشور.
- تعليقان كحد أقصى لكل مستخدم على المنشور نفسه.
- المعاملة الذرية تمنع تجاوز الحد عند الطلبات المتزامنة.
- تُحسب التعليقات القديمة ذات مفاتيح `push()`، وتحتفظ `comments/__codeexUsageV1` بعدادات الاستخدام حتى بعد حذف المشرف لتعليق.
- تعليقات المجموعات الخاصة تتحقق من وجود المنشور ومن عضوية المستخدم المقبولة قبل الكتابة؛ قراءة محتوى المجموعة الخاصة لا تتغير.
- ترتيب التعليقات في الواجهة من الأحدث إلى الأقدم، مع عرض أول 10 ثم زر يحمّل 10 إضافية في كل مرة.

## الإشعارات

عند تعليم الإشعار كمقروء يُحفظ `readAt`، ثم يحذفه التطبيق بعد مرور 6 أيام. يجري التنظيف تلقائياً إذا بقي الموقع مفتوحاً، أو عند فتحه/تسجيل الدخول لاحقاً إذا كان مغلقاً وقت انتهاء المدة. لم أضف مهمة مجدولة خادمية كي لا أفرض خدمة جدولة أو تكلفة إضافية على مشروع Firebase. الإشعارات القديمة التي ليس لديها `readAt` تبدأ مدة الاحتفاظ بها عند أول تشغيل للنسخة الجديدة؛ لا يمكن استعادة تاريخ قراءتها السابق.
